# Azure new features — Terraform practice labs

Companion Terraform labs for the [Azure new features](https://www.youtube.com/playlist?list=PLG_D4OGqLpRE) YouTube playlist from the Network Technician channel.

Each video has its own folder. Copy `terraform.tfvars.example` to `terraform.tfvars`, fill in your values, then run `terraform init`, `terraform plan`, and `terraform apply` from that folder. Destroy the lab when you are finished.
